## Checked, nothing found

- **XSS (A03):** no `dangerouslySetInnerHTML` added; scanned codes, customer names, comments and toasts render as
  React text. The inline script in `spa.html.twig` reads `kf.theme`/`kf.locale` from localStorage and sets
  `data-theme`/`lang` only from a whitelist (`light|dark`, `en|es`); it writes no HTML.
- **Access control (A01):** the UI now hides actions the session's roles do not reach (`useCan`), but every endpoint
  keeps its `#[IsGranted]`; no API or `security.yaml` change (role hierarchy byte for byte).
- **Browser storage:** only preferences (`kf.theme, kf.locale, kf.warehouse, kf.scanMode, kf.sound, kf.sidebar,
  kf.scanIntroSeen`), no token or personal data; every access wrapped in try/catch.
- **Camera:** `getUserMedia` only after the user presses the camera button; frames are decoded in the page
  (BarcodeDetector, else the lazily loaded `@zxing/browser`) and never uploaded. Needs HTTPS, which production has
  (user confirmed).
- **Development-only surface:** `/admin/_kit` is compiled out of production builds (`process.env.NODE_ENV` in
  `app/routes.tsx`) and calls no API.
- **Dependencies (A06):** `composer audit` and `npm audit --omit=dev` clean; fonts are self-hosted (no third-party
  requests).
